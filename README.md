
TechStore is a UI/UX design project for a mobile and desktop application focused on selling tech equipment. This project was created using Figma as part of a student's UI/UX coursework.

--- 

## 🎯 Project Goal

The primary objective was to create a modern, intuitive, and user-friendly interface for an online tech store. The design emphasizes:

- **Effortless Navigation**: Simple and clear ways for users to find what they need.
- **Product Clarity**: Well-organized presentation of products for easy browsing.
- **Swift User Experience (UX)**: Streamlined interactions to ensure a fast and pleasant shopping journey.

--- 

## 🖥️ Platforms

- 📱 **Mobile App**: Designed for both iOS and Android devices.
- 💻 **Desktop/Web App**: Interface tailored for web and desktop use.

--- 

## 🛠️ Tools Used

- **Figma**: The primary tool for UI/UX design and prototyping.
- **FigJam**: Utilized for user journey mapping and brainstorming sessions.

--- 

## 🎨 Key UI Elements

The design includes essential screens and components for an e-commerce experience:

- **Home Page**: Featuring a product listing.
- **Product Details Page**: Showcasing individual product information.
- **Shopping Cart**: For managing selected items.
- **Checkout Process**: A streamlined flow for completing purchases.
- **Login / Signup Screens**: User authentication interfaces.

--- 

## 🧭 User Journey

The typical user flow is designed to be straightforward:

1.  **Launch App**: User opens the TechStore application.
2.  **Browse Products**: User explores items on the home page.
3.  **View Details**: User selects a product to see more information.
4.  **Add to Cart**: User adds the desired product to their shopping cart.
5.  **Complete Purchase**: User proceeds through the checkout process.

--- 

## 🧠 UX Focus

Special attention was given to optimizing the user experience through:

- **Minimal Clicks**: Reducing the number of steps required to make a purchase.
- **Clear Information Hierarchy**: Organizing content logically for easy comprehension.
- **Visually Clean Design**: Maintaining a modern and uncluttered aesthetic.
